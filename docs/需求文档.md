## 1. 项目概述

### 1.1 一句话定位

一个纯静态、数据驱动的营养学基础知识科普网站：把「食物 → 营养素 → 分类」这条链路讲清楚，重点解决「精制碳水 vs 慢碳」「优质蛋白有哪些」「脂肪怎么分」三类高频困惑。

### 1.2 目标用户

| 用户 | 核心诉求 |
|---|---|
| 普通大众 | 搞懂日常食物到底属于什么营养类别，能不能吃、怎么吃 |
| 减脂/健身入门 | 需要查具体食物的碳水/蛋白/脂肪含量与 GI 值 |
| 学生/备考 | 需要体系化的分类框架和名词定义 |

### 1.3 核心价值

1. **有体系**：不是零散知识点的堆砌，而是「总览 → 三大产能营养素 → 食物图谱」的自上而下结构。
2. **可对照**：所有概念都配具体食物举例和数字，杜绝空谈。
3. **易维护**：全部内容存在 JSON 中，改数据 = 改网站，不动代码。

### 1.4 明确不做（Out of Scope）

- 不做用户系统、登录、收藏、评论（无后端）
- 不做个性化饮食计划 / 热量计算器（v1 不含，可作为 v2 扩展）
- 不做疾病治疗、临床营养建议（仅科普，站内需有免责声明）
- 不做实时数据接口调用

## 3. 内容明细

### 3.1 营养素总览

**内容点：**

- 六大营养素：碳水化合物、蛋白质、脂肪、维生素、矿物质、水（部分体系把膳食纤维单列为第七类）
- 宏量营养素（碳水 / 蛋白 / 脂肪，需克级摄入）vs 微量营养素（维生素 / 矿物质，需毫克微克级）
- 三大产能营养素能量密度：碳水 4 kcal/g，蛋白质 4 kcal/g，脂肪 9 kcal/g（酒精 7 kcal/g）
- 各营养素的四大功能：供能 / 构成身体 / 调节代谢 / 促进吸收

**呈现形式：** 卡片矩阵（6 张卡），每卡含「别名 / 是否供能 / 能量密度 / 主要来源 / 每日建议占比」。

### 3.2 碳水化合物

#### 3.2.1 按分子结构分类

| 类别 | 组成 | 代表食物 |
|---|---|---|
| 单糖 | 1 个糖分子 | 葡萄糖、果糖（水果/蜂蜜）、半乳糖 |
| 双糖 | 2 个单糖 | 蔗糖（白糖）、乳糖（牛奶）、麦芽糖 |
| 寡糖 | 3–10 个单糖 | 低聚果糖、棉子糖（豆类产气元凶） |
| 多糖 | 10 个以上 | 淀粉（米面土豆）、糖原、膳食纤维 |

#### 3.2.2 精制碳水 vs 慢碳【网站核心章节】

**分类定义：**

- **精制碳水（快碳 / 简单碳水）**：经高度加工，去除了麸皮、胚芽和膳食纤维，只剩淀粉或添加糖。消化快、吸收快、血糖升得快。
- **慢碳（复合碳水 / 优质碳水）**：保留完整谷物结构或天然纤维，消化吸收慢，血糖平缓上升，饱腹感强。

**区别对照表（页面用可视化对比呈现）：**

| 对比维度 | 精制碳水（快碳） | 慢碳（复合碳水） |
|---|---|---|
| 加工程度 | 高度加工，去麸皮/胚芽 | 加工程度低，保留完整结构 |
| 膳食纤维 | 极少（<1g/100g） | 丰富（3–10g/100g） |
| 消化速度 | 快，30–60 分钟升糖 | 慢，2–4 小时缓释 |
| GI 值 | 高（≥70） | 低（≤55） |
| 血糖曲线 | 陡升陡降，易饿易困 | 平缓，供能稳定 |
| 饱腹感 | 差 | 强 |
| 代表食物 | 白米饭、白馒头、白面包、面条、米粉、糕点、饼干、含糖饮料、糖果、白粥 | 燕麦、糙米、藜麦、全麦面包、荞麦、玉米、红薯、紫薯、山药、土豆（带皮）、豆类、莲藕 |
| 摄入建议 | 控制比例，避免空腹单吃 | 作为主食主体 |

**关键澄清（避免常见混淆）：**

- 「碳水」不等于「主食」：水果、牛奶、蔬菜、豆类都含碳水。
- 「红薯是碳水」不代表它和「白糖是碳水」等价 —— 分类要落到「精制 / 非精制」这一层。
- 「慢碳」不是指吃的速度慢，而是指升糖速度慢。
- 白粥 GI 值比白米饭更高（糊化更充分），属于典型快碳。
- 冷米饭、冷藏后的土豆会产生抗性淀粉，GI 略降（延伸知识点）。

#### 3.2.3 GI / GL

- GI（血糖生成指数）：以葡萄糖 100 为基准，≤55 低，56–69 中，≥70 高
- GL（血糖负荷）= GI × 可利用碳水克数 ÷ 100，比 GI 更贴近实际影响
- 影响 GI 的因素：加工程度、烹饪方式、纤维含量、脂肪蛋白搭配、成熟度
- 常见食物 GI 速查表（≥20 条）

#### 3.2.4 膳食纤维

- 可溶性纤维（燕麦 β-葡聚糖、果胶、豆类）：延缓糖吸收、降胆固醇、喂养肠道菌群
- 不可溶性纤维（麸皮、纤维素）：促肠道蠕动、防便秘
- 建议摄入量：成人 25–30 g/天（国人实际平均约 10–13 g）

#### 3.2.5 碳水常见误区

1. 「不吃碳水才健康」→ 碳水是大脑和红细胞的主要燃料，问题在质量不在总量
2. 「水果含糖所以要戒」→ 水果的糖被纤维和水分包裹，GI 通常低于精制糖
3. 「粗粮吃得越多越好」→ 过量影响矿物质吸收，且部分粗粮 GI 也不低（如即食燕麦片）
4. 「0 蔗糖 = 无糖」→ 可能含果葡糖浆、麦芽糊精

### 3.3 蛋白质

#### 3.3.1 氨基酸基础

- 9 种必需氨基酸（人体不能合成，必须从食物获取）：组氨酸、异亮氨酸、亮氨酸、赖氨酸、蛋氨酸、苯丙氨酸、苏氨酸、色氨酸、缬氨酸
- 条件必需氨基酸：半胱氨酸、酪氨酸、精氨酸、谷氨酰胺等
- 非必需氨基酸：人体可自行合成
- 记忆口诀（可作为页面彩蛋）：**甲（缬）携（亮）一（异亮）本（苯丙）书（苏）** + 色（色氨酸）、赖（赖氨酸）、蛋（蛋氨酸）、组（组氨酸）

#### 3.3.2 按来源分类

| 类型 | 代表食物 | 特点 |
|---|---|---|
| 动物蛋白 | 鸡蛋、牛奶、鱼虾、鸡胸、牛肉、瘦猪肉、乳清蛋白 | 氨基酸谱完整，吸收率高；多数含饱和脂肪 |
| 植物蛋白 | 大豆及豆制品、藜麦、荞麦、鹰嘴豆、坚果、谷物 | 富含纤维、无胆固醇；部分缺必需氨基酸 |

#### 3.3.3 按氨基酸组成分类【网站核心章节】

| 类别 | 定义 | 举例 |
|---|---|---|
| **完全蛋白**（优质蛋白） | 含全部 9 种必需氨基酸，种类齐全、比例接近人体需要，可维持生命与生长发育 | 鸡蛋、牛奶、鱼肉、牛肉、鸡胸肉、虾、**大豆**（植物中唯一的完全蛋白） |
| **半完全蛋白** | 必需氨基酸种类齐全，但某几种数量不足，比例不当，只能维持生命、不能促进生长 | 米、面、土豆、玉米（赖氨酸/苏氨酸不足） |
| **不完全蛋白** | 缺少 1 种及以上必需氨基酸，既不能维持生命也不能促进生长 | 玉米胶蛋白、动物明胶、豌豆胶（缺色氨酸） |

#### 3.3.4 优质蛋白评判标准

- **PDCAAS**（蛋白质消化率校正氨基酸评分）：0–1，1 分为满分。鸡蛋、牛奶、大豆分离蛋白、乳清蛋白均为 1.0
- **DIAAS**（可消化必需氨基酸评分）：更严格的新标准，>100 为优质
- **BV**（生物价）：鸡蛋 94（参考值 100）、牛奶 85、鱼 83、牛肉 80、米 77、面粉 52
- 常见优质蛋白食物蛋白含量表（每 100 g，生重）：

| 食物 | 蛋白质 (g) | 备注 |
|---|---|---|
| 鸡蛋 | 13.3 | 全蛋，氨基酸评分最高 |
| 鸡胸肉 | 24.6 | 高蛋白低脂 |
| 瘦牛肉 | 20.2 | 富含铁、锌、B12 |
| 三文鱼 | 20.0 | 同时提供 ω-3 |
| 虾仁 | 18.6 | 低脂 |
| 巴氏牛奶 | 3.3 | 酪蛋白 + 乳清蛋白 |
| 希腊酸奶 | 9–10 | 经浓缩，蛋白更高 |
| 大豆（干） | 35.0 | 植物完全蛋白 |
| 北豆腐 | 12.2 | 钙含量也高 |
| 乳清蛋白粉 | 80+ | 吸收最快的蛋白 |

#### 3.3.5 蛋白质互补原则

- 原理：不同食物限制性氨基酸不同，搭配吃可互相补齐，提高整体利用率
- 经典组合：米饭 + 豆类（米饭缺赖氨酸、豆类富含赖氨酸；豆类缺蛋氨酸、米饭富含蛋氨酸）→ 红豆饭、八宝粥、豆浆配馒头
- 实操建议：一餐内多样化搭配优于单一种类，不必精确计算

#### 3.3.6 摄入量建议

- 普通成人：0.8–1.0 g/kg 体重/天
- 老年人与增肌需求：1.2–1.6 g/kg
- 力量训练者：1.6–2.2 g/kg
- 单餐 20–40 g 为较优利用窗口（"蛋白质分配"知识点）

#### 3.3.7 蛋白质常见误区

1. 「植物蛋白一定不如动物蛋白」→ 大豆是例外，且植物蛋白有纤维红利
2. 「吃蛋白粉伤肾」→ 健康人群在合理范围内无证据支持
3. 「高蛋白 = 多吃肉」→ 红肉过量与饱和脂肪、加工肉风险相关
4. 「胶原蛋白吃了补皮肤」→ 属不完全蛋白，会被分解为氨基酸，不直接转化为皮肤胶原

### 3.4 脂肪

#### 3.4.1 按饱和度分类【网站核心章节】

| 类别 | 结构特征 | 常温状态 | 代表来源 | 健康取向 |
|---|---|---|---|---|
| 饱和脂肪 SFA | 碳链无双键，结构饱和 | 固态 | 猪油、黄油、牛油、椰子油、肥肉、全脂奶 | 建议 <10% 总热量 |
| 单不饱和脂肪 MUFA | 含 1 个双键 | 液态 | 橄榄油、山茶油、牛油果、坚果 | 相对友好，地中海饮食核心 |
| 多不饱和脂肪 PUFA | 含 2 个及以上双键 | 液态 | 大豆油、玉米油、葵花籽油、深海鱼、亚麻籽 | 需注意 ω-6/ω-3 比例 |
| 反式脂肪 TFA | 氢化产生的反式双键 | 半固态 | 部分氢化植物油、人造奶油、起酥油、反复油炸食品 | 建议 <1% 总热量，越少越好 |

#### 3.4.2 反式脂肪

- 工业来源：部分氢化植物油（植脂末、奶精、代可可脂、酥皮点心、油炸食品）
- 天然来源：反刍动物肉奶中少量共轭亚油酸（含量低，影响小）
- 标签识别：配料表中出现「氢化植物油 / 植脂末 / 代可可脂 / 麦淇淋 / 起酥油」需警惕；标注「0 反式脂肪」时若饱和脂肪较高也可能是替代品
- 危害：升高 LDL、降低 HDL，同时增加心血管风险（唯一「零摄入推荐」的脂肪类型）

#### 3.4.3 按双键位置分类（Omega 系列）

| 名称 | 学名 | 关键成员 | 主要来源 | 人体作用 |
|---|---|---|---|---|
| ω-3 | α-亚麻酸 ALA | EPA、DHA（由 ALA 转化，效率 <10%） | 亚麻籽油、奇亚籽、核桃、深海鱼（三文鱼/沙丁鱼/鲭鱼） | 抗炎、心血管、大脑与视网膜 |
| ω-6 | 亚油酸 LA | 花生四烯酸 AA | 大豆油、玉米油、葵花籽油、坚果 | 必需，但过量促炎 |
| ω-9 | 油酸 | ——（非必需） | 橄榄油、山茶油、牛油果 | 改善血脂 |

- 必需脂肪酸只有两种：亚油酸（ω-6）与 α-亚麻酸（ω-3）
- **ω-6 : ω-3 比例**：现代饮食约 15–20:1，理想 4:1 以内 → 实操建议是「增加深海鱼和亚麻籽，而不是完全杜绝大豆油」

#### 3.4.4 胆固醇

- 食物胆固醇（蛋黄、动物内脏、虾） vs 血胆固醇（人体 70–80% 自体合成）
- 对多数人而言，膳食胆固醇对血胆固醇影响有限，但「高反应者」和已患心血管疾病者需控制
- 常见误解：吃蛋黄必然血脂高；「零胆固醇」植物油不等于可以无限量

#### 3.4.5 常见油脂脂肪酸构成表

页面以横向堆叠条（stacked bar）呈现每 100 g 油脂中 SFA / MUFA / PUFA 的占比：

- 椰子油（SFA 极高）、黄油、猪油
- 橄榄油（MUFA 高）、山茶油、牛油果油
- 大豆油、玉米油、葵花籽油（PUFA 高、ω-6 为主）
- 亚麻籽油（ω-3 高，不耐高温）
- 深海鱼油（EPA/DHA）

#### 3.4.6 脂肪常见误区

1. 「吃脂肪长脂肪」→ 决定体重的是总热量，脂肪只是能量密度高（9 kcal/g）
2. 「无脂食品更健康」→ 常以添加糖补口感，且可能含反式脂肪
3. 「植物油随便吃」→ 植物油热量同样是 9 kcal/g，且 ω-6 过量有代价
4. 「黄油比人造奶油安全」→ 两者都不理想，优选橄榄油/山茶油
5. 「坚果会上火发胖」→ 适量（30 g/天）坚果与更低心血管风险相关

## 5. 技术方案

### 5.1 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 架构 | 纯静态 SPA（单 index.html + hash 路由） | 无后端，导航统一，数据驱动渲染最自然 |
| 样式 | Tailwind CSS | 用户指定 |
| 脚本 | 原生 ES Module JS（无框架） | 零构建依赖，双击即用 |
| 数据 | 多个 JSON 文件，`fetch()` 读取 | 用户指定，便于后期修改 |
| 部署 | 任意静态托管 / 本地静态服务器 | 无服务端依赖 |

### 5.2 关于 Tailwind 的两种引入方式

| 方式 | 适用 | 说明 |
|---|---|---|
| **A. CDN（Tailwind Play CDN）** | 开发阶段 / 快速预览 | `<script src="https://cdn.tailwindcss.com"></script>`，零配置，可自定义主题色 |
| **B. CLI 构建静态 CSS** | 正式发布 | 生成一份压缩后的 `dist.css`，体积小、无运行时开销 |

**推荐：先用 A 开发，功能完成后切 B 产出。** 两者不冲突，切 B 只需替换一个 `<link>`。

### 5.3 注意：fetch JSON 的同源限制

浏览器对 `file://` 协议下的 `fetch()` 有 CORS 限制，直接双击 `index.html` 会读不到 JSON。

**解决方案（三选一，v1 采用方案 1）：**

1. 本地起静态服务器预览：`python -m http.server 8080`（项目已提供 `start.bat` 一键启动）
2. 把 JSON 内联进 JS（`data/foods.js` 导出对象）—— 牺牲「纯 JSON 文件」的可读性，不推荐
3. 部署到静态托管后自然正常

> 项目会附带一个 `start.bat`（Windows 双击启动本地服务并打开浏览器），确保用户不踩这个坑。

## 6. 交互与视觉

### 6.1 视觉风格

  - 快碳 / 风险 / 警示 → 红色系 `#dc2626`

  - 脂肪 → 琥珀色 `#d97706`
- 背景：浅色（`gray-50`），卡片白底 + 轻阴影 + 圆角 `rounded-xl`
- 字体：系统中文字体栈（PingFang SC / Microsoft YaHei），正文 16px，行高 1.75
- 圆角统一 `rounded-xl`，间距统一 4 的倍数

### 6.2 交互要求

| 交互 | 要求 |
|---|---|
| 导航 | 顶部固定导航栏，当前页高亮，移动端折叠为汉堡菜单 |
| 页内锚点 | 长页面右侧/顶部提供章节锚点导航（sticky） |
| 食物筛选 | 输入即时过滤（debounce 200ms），筛选条件可叠加，结果计数实时显示 |
| 食物对比 | 最多选 2 项，超出时提示替换 |
| 图表 | 脂肪酸堆叠条用纯 CSS/内联 SVG，不引第三方图表库 |
| 响应式 | 断点 sm / md / lg，移动端单列，桌面端 2–3 列 |
| 无障碍 | 语义化标签、对比度 ≥4.5:1、键盘可操作筛选与对比 |

### 6.3 页面骨架（统一布局）

```
[ 顶部导航栏（sticky） ]
[ 页面标题区：标题 + 一句话导语 ]
[ 目录锚点（sticky，桌面端左侧/顶部） ]
[ 内容区：由 JSON sections 渲染 ]
[ 上一页 / 下一页 切换 ]
[ 页脚：数据来源 + 免责声明 ]
```
